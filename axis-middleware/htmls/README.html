1. System map

flowchart LR
    U["User / Postman"] --> M["axis-middleware<br/>Express :3000"]
    U --> P["axis-playground<br/>Next.js :3001"]
    P --> M
    M --> A["axis library<br/>semantic layer"]
    A --> PG[("PostgreSQL<br/>database po")]
    A --> OS[("OpenSearch<br/>index purchase-requisitions")]
    A --> EM["Embeddings<br/>MiniLM 384-dim"]
Direction: clients send JSON DSL, never SQL. HTTP reads hit OpenSearch only.

2. The three packages

FolderWhat it isPortRole
axis/TypeScript library—Models, validation, AST, resolver, compilers, planner, indexer, security, cache, embeddings
axis-middleware/Express API3000JWT auth, routes, DB/OS/embeddings wiring
axis-playground/Next.js UI3001Models, query builder, raw JSON, auth panel, response viewer

Dependency rule: playground → middleware → axis → infrastructure. The library never sees JWTs; the UI never sees SQL; the middleware never builds DSL.

3. Prerequisites

Node 20+, PostgreSQL with po, OpenSearch + embeddings reachable. Middleware .env: DATABASE_URL, AXIS_JWT_SECRET, OPENSEARCH_URL, EMBEDDING_URL / PROVIDER / MODEL / DIMENSIONS.

4. Build / run / test

cd axis && npm run build && npm pack
cd ../axis-middleware && npm install file:../axis/axis-1.0.0.tgz
npx tsx scripts/seed-po.ts
npx vitest run tests/e2e-searchAndFilter.test.ts
npm run build && npm start
cd ../axis-playground && npm install && npm run dev
npm run test
Stale node_modules/axis (forgot pack + reinstall) is the #1 phantom-error source.

6. The model

PurchaseRequisitions → upeg.requisition_deails. Axes id, status, department, createdBy, amount, createdAt, hasAssignedBuyer; metrics newCount, pendingCount, assignedCount; index purchase-requisitions.

Caveat: hasAssignedBuyer / assignedCount need upeg.requisition_item, absent from po.
