Axis

Complete adoption requirements — prerequisites, middleware contracts, and current deployment status for the Axis semantic analytics library.

v1.0.0

Axis is a semantic analytics layer that sits between an Express HTTP server and a PostgreSQL database. You define Models (named axes + metrics), accept a JSON query DSL, and Axis compiles that into parameterized SQL — and optionally routes it to OpenSearch for full-text or semantic search.

This document answers two questions:

  • What must exist before you can run Axis? (Prerequisites)
  • What must your middleware implement? (Middleware Contract)

3. Project Configuration

3.1 ESM Mode — Non-Negotiable

Axis is ESM-only. The consuming project must also run in ESM mode:

// package.json
{ "type": "module" }
🚫

Importing Axis from a CJS project fails immediately with ERR_REQUIRE_ESM. There is no compatibility shim.

3.2 TypeScript Compiler Options

{
  "compilerOptions": {
    "target": "ES2022",
    "module": "NodeNext",              // MANDATORY
    "moduleResolution": "NodeNext",  // MANDATORY — resolves package.json exports
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true
  }
}
ℹ️

With NodeNext resolution, all relative imports inside your source must use explicit .js extensions — e.g. import { foo } from "./utils.js".

3.3 Installing the Library

# From your middleware root
npm install --save "file:../axis/axis-1.0.0.tgz"
⚠️

After rebuilding Axis, re-run npm pack inside axis/ and then npm install in the middleware. A stale node_modules/axis is the most common source of broken imports.

Part 2 — Middleware Contract

Everything the consuming middleware application must implement to correctly use Axis.

5. Install & Import Axis

All public exports come from a single "axis" entry point. No deep-import paths.

import {
  Axis,
  ModelRegistry,
  OpenSearchAdapter,
  OllamaEmbeddingProvider,
  OpenAICompatibleEmbeddingProvider,
  defineModel,
  SecurityContextError,
  buildOpenSearchSecurityFilters,
} from "axis";

import type {
  AxisQuery, AxisSecurityConfig, ModelDefinition,
  EmbeddingProvider, SearchAdapter, SearchQuery, QueryResult,
} from "axis";

6. Define & Register Models

The middleware must define at least one ModelDefinition and register it before instantiating Axis. Queries for unregistered models throw ResolutionError (HTTP 422).

const registry = new ModelRegistry();
registry.register(PurchaseRequisitions);

// Pass registry into Axis — private registry is recommended
const axis = new Axis({ database: { url }, registry });

7. Instantiate Axis

Cache is explicitly disabled. The Axis instance is constructed with cache: { enabled: false } so every request always reaches OpenSearch. The library never reads process.env — the middleware passes everything resolved.

const axis = new Axis({
  database: { url: databaseUrl },    // ✅ Required
  registry,                             // Model registry
  cache: { enabled: false },            // ❌ Cache explicitly off
  security,                             // Security mappings (when JWT enabled)
  searchAdapter,                        // OpenSearch adapter
  embeddings: { instance: provider }, // Embedding provider
});

8. Wire OpenSearch Adapter

The middleware is OpenSearch-only over HTTP. Without this, /search and /os/* return 503.

import { OpenSearchAdapter } from "axis";

const searchAdapter = new OpenSearchAdapter({
  enabled: true,
  url: process.env.OPENSEARCH_URL,          // http://10.0.2.147:9200
  // username / password only if cluster requires auth
  ssl: { rejectUnauthorized: true },
});

Each model must also declare a search block for it to be indexed and searchable:

search: {
  index: "purchase-requisitions",   // OpenSearch index name
  searchable: ["department"],        // full-text search axes
  embeddingInput: ["department"],   // axes concatenated as embedding input text
  embeddingField: "embedding",      // knn_vector field name in OpenSearch
}

9. Wire Embedding Provider

Required for search.type = "semantic" or "hybrid". This deployment uses openai-compatible:

import { OpenAICompatibleEmbeddingProvider } from "axis";

const provider = new OpenAICompatibleEmbeddingProvider({
  baseURL: process.env.EMBEDDING_URL,              // http://10.0.2.147:8000
  model:   process.env.EMBEDDING_MODEL,             // sentence-transformers/all-MiniLM-L6-v2
  dimensions: Number(process.env.EMBEDDING_DIMENSIONS), // 384
});

For Ollama deployments, swap to OllamaEmbeddingProvider with the same options shape.

10. Wire Security & JWT Auth

🔐

Ownership rule: Axis handles authorization (row-level security context). The middleware handles authentication (JWT verification). The library never sees tokens.

  1. Middleware verifies the JWT 
    import jwt from "jsonwebtoken";
const payload = jwt.verify(token, secret);
// Accepts: { sub, tenantId, roles? }  OR  { userId, tenantId, role? }
  2. Convert claims to AxisContext 
    import type { AxisContext } from "axis";
const context: AxisContext = {
  user:   payload.sub      ?? payload.userId,
  tenant: payload.tenantId ?? payload.tenant,
  roles:  payload.roles    ?? [],
};
  3. Register security mappings with Axis 
    const security: AxisSecurityConfig = {
  mappings: {
    tenant: {
      contextKey: "tenant",
      column: "tenant_id",
      sessionKey: "app.tenant_id",
      required: true,
    },
    user: {
      contextKey: "user",
      column: "created_by",
      sessionKey: "app.user_id",
      required: true,
      searchField: "createdBy",  // OpenSearch term filter field
    },
  },
};
  4. Pass context per request 
    app.post("/search", async (req, res) => {
  const context = req.axisContext; // set by auth middleware
  const result = await axis.searchDocuments(req.body, { context });
  res.json(result);
});

12. Handle Errors Correctly

Axis throws typed errors. The middleware must map them to correct HTTP status codes.

Error NameHTTP StatusTrigger
ValidationError400Malformed AxisQuery
SyntaxError (body-parser)400Malformed JSON body
AuthError401 / 403JWT missing / invalid / expired
SecurityContextError403Required security context value absent
ResolutionError422Unknown axis/metric, unregistered model
CompilationError422Query cannot be compiled to DSL
ExecutionError502Search execution failed
Other500Unexpected internal error

A 4-argument error handler is mandatory — Express identifies error handlers by arity. Register it last:

// Must be the LAST app.use() call
app.use((err: unknown, _req: Request, res: Response, _next: NextFunction) => {
  res.status(statusForError(err)).json({
    error: {
      message: err instanceof Error ? err.message : String(err),
      code: err instanceof Error ? err.name : "InternalError",
    },
  });
});

13. Graceful Shutdown

axis.close() must be called on process termination. This drains the PostgreSQL pool and closes all connections to OpenSearch and the embedding provider.

async function shutdown(signal: string): Promise<void> {
  server.close();
  await axis.close(); // closes: pg Pool + OpenSearch + embedding provider
  process.exit(0);
}
process.on("SIGINT",  () => void shutdown("SIGINT"));
process.on("SIGTERM", () => void shutdown("SIGTERM"));
🚫

Not calling axis.close() causes the Node.js process to hang indefinitely — the open pg pool keeps the event loop alive.

Full Model Example

import { defineModel } from "axis";

export const PurchaseRequisitions = defineModel({
  name: "PurchaseRequisitions",
  source: { type: "table", table: "upeg.requisition_deails" },
  axes: {
    id:         { sql: "requisition_id", type: "string", primaryKey: true },
    status:     { sql: "status",          type: "number" },
    department: { sql: "department_name",  type: "string" },
    createdBy:  { sql: "created_by",      type: "string" },
    amount:     { sql: "amount",          type: "number" },
    createdAt:  { sql: "created_date",    type: "time" },
  },
  metrics: {
    newCount:     { type: "count" },
    pendingCount: { type: "count", sql: "requisition_id",
                    filters: [{ field: "status", operator: "equals", value: 1 }] },
  },
  security: {
    function: { name: "upeg.get_requisitions_for_user", args: ["userId"] },
  },
  search: {
    index: "purchase-requisitions",
    searchable: ["department"],
    embeddingInput: ["department"],
    embeddingField: "embedding",
  },
});

15. Query DSL Contract

Clients send AxisQuery to /search. Axis validates at runtime — pass req.body directly.

interface AxisQuery {
  model: string;        // Required — registered model name
  axes?: string[];      // GROUP BY dimensions
  metrics?: string[];  // Aggregations
  filters?: Filter[];  // WHERE conditions
  orderBy?: OrderBy[]; // Result ordering
  limit?: number;
  offset?: number;
  search?: SearchInput; // Required for /search
  cacheTtl?: number;   // Ignored — cache is disabled
}

SearchInput

{
  type: "fulltext" | "semantic" | "hybrid";
  text: string;
  fields?: string[];  // Override default searchable axes
  k?: number;        // k-NN neighbors for vector search
}

Filter Operators

"equals" | "notEquals" | "greaterThan" | "greaterThanOrEqual"
| "lessThan" | "lessThanOrEqual" | "in" | "notIn"
| "contains" | "startsWith" | "endsWith"
| "isNull" | "isNotNull"

16. Security Context Contract

With AXIS_JWT_SECRET set, every request to /search and /os/* must carry Authorization: Bearer <JWT>.

JWT ClaimRequired?Maps to
sub or userIdRequiredAxisContext.user
tenantId or tenantRequiredAxisContext.tenant
roles or roleOptionalAxisContext.roles

Because cache is disabled, there is no cache-key isolation concern. Security context is still applied as PostgreSQL SET LOCAL session variables and as OpenSearch term filters (createdBy, tenant_id) on every request.

18. Common Pitfalls

ProblemCauseFix
Cannot find module 'axis' Stale .tgz in node_modules npm pack in axis/, then npm install in middleware
ERR_REQUIRE_ESM App is CJS, Axis is ESM-only Add "type": "module", switch TS to NodeNext
Database configuration requires 'url' or 'host' DATABASE_URL is empty Set the environment variable
Model "X" is not registered registry.register() not called Register all models before the first request
Semantic search fails: "requires an embedding provider" No embedding provider configured Set EMBEDDING_URL + EMBEDDING_MODEL
Search returns 503 searchAdapter not passed to Axis Set OPENSEARCH_URL
JWT 401 on every request Token expired or wrong secret Regenerate token; verify AXIS_JWT_SECRET matches the signing key
Embedding dimension mismatch error EMBEDDING_DIMENSIONS doesn't match OpenSearch mapping Both must be 384 (or whatever the model outputs)
Node process hangs on exit axis.close() not called Add SIGINT / SIGTERM handlers
/query returns 404 SQL HTTP route was removed from this middleware Use /search — this middleware is OpenSearch-only over HTTP
